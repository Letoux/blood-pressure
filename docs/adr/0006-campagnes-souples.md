# Campagnes souples : une campagne incomplète reste valable, mais elle est signalée

On peut saisir une mesure à tout moment. Une campagne commence réellement le jour de sa première mesure. Une campagne incomplète reste valable : sa moyenne porte sur les mesures présentes. Elle est mise en évidence partout, avec son nombre de mesures (par exemple 14/18) et ses créneaux manquants, pour que le médecin le voie.

**Option écartée** : une saisie stricte, limitée aux créneaux d'une campagne active. Elle faisait perdre des données réelles pour une simple question de forme.

# Saisie en ligne uniquement, sans synchronisation hors ligne

La PWA ne met pas les mesures en file d'attente hors ligne. Sans réseau, elle affiche un avertissement et le formulaire garde ce qui a été tapé jusqu'au retour de la connexion. La synchronisation hors ligne (file d'attente et résolution de conflits) coûterait cher pour un usage où l'on mesure presque toujours chez soi, avec du réseau.
